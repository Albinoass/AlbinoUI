# Known limitations

- **No live-client validation yet.** Secure clicks, modifier targeting, drag/drop, direct CLICK bindings, native binding overrides, Rogue stealth paging and taint/combat restrictions are not proven by the Cloud mocks. Do not label this build fully validated before those tests pass.
- Client **1.60.1 / 16001** is community-reported. The exact runtime build, Lua version and Forever-specific API changes must be read in the in-game settings panel.
- Swing events may not exist on Forever. Bars remain blank until public, hand-specific swing events are actually observed. They do not repeat without subsequent events. Haste preserves estimated fractional progress; unexposed parry haste and server-specific reset effects cannot be measured. Successful casts conservatively invalidate both estimates, including casts that might not reset swings on a particular server.
- Secret/restricted resource or cooldown values are withheld, not reconstructed. Optional numbers show `?` for unavailable health/energy. A client that restricts these player values will need a supported native presentation API before numeric HUD parity is possible.
- The primary has fixed normal and Rogue stealth pages, not arbitrary action-bar cycling. The secondary uses native page 6, so it mirrors and edits Blizzard's bottom-left slots. Neither bar is a general vehicle, possession, pet, druid stance or override-bar replacement. Existing override bindings can interfere with those special interfaces; disable Albino UI for such content until validated.
- Blizzard's bars remain intact. Other bar replacements may compete for bindings and state; test without them first. Hiding a custom bar removes its native key overrides; it does not erase native actions/bindings. A direct keybinding to a named custom button is separate from that visibility preference.
- Action slots and their contents belong to WoW. Uninstalling/resetting AlbinoUIDB does not restore old native slot contents. Back up WTF before initial use.
- Tracker GCD filtering uses a ≤1.5-second cutoff. Very short real cooldowns may be treated as ready; no charge-specific tracker, aura-duration tracking, server tick prediction or rotation suggestions are included.
- Settings are per character. There is no cross-character profile importer, controller UI, Edit Mode integration or localization pack. Numeric spell IDs work across locales; labels are English. Combo rendering supports at most ten segments.
- Lua mocks deliberately cannot reproduce native cursor security, hardware events, protected execution or WoW taint propagation. They are useful regression tests, not a client emulator.
- The current Cloud network policy denies `api.github.com`. Git read access does not prove push or PR API authorization. See the final delivery report for actual branch/PR results; no release publication or merge is performed.
